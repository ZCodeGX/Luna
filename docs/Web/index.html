Documentación de Luna

Luna es un lenguaje de programación pequeño, embebible y con CLI estilo Python. Esta página resume la guía completa disponible en formato Markdown.

Requiere un compilador C11 y Python 3. La sintaxis y la API C pueden cambiar entre versiones; no se recomienda uso en producción.

Inicio rápido

Compila el intérprete y ejecuta tu primer programa:

./luna.py build
./build/luna -c 'let x = 1'
./build/luna programa.luna

Sin argumentos, ./build/luna abre el REPL. Con - lee el programa desde stdin.

Sintaxis básica

Los bloques se delimitan por indentación con espacios. Los tabuladores en la indentación son un error. El carácter # inicia un comentario de línea y los dos puntos antes de un bloque son opcionales.

let nombre = "Luna"
const pi = 3.14159
# esto es un comentario

fn saludar(quien)
    print("Hola", quien)

Palabras reservadas

and break catch const continue else false fn for if import in let mod nil not or pub return throw true try while

La división / y la potencia ** producen float. Dividir entre cero es un error. El operador + no concatena cadenas.

Control de flujo

if x > 10
    print("grande")
else if x > 5
    print("mediano")
else
    print("pequeño")

while x > 0
    x = x - 1

if/else if/else y while están implementados. for, break y continue son aceptados por el parser pero aún no se compilan.

Funciones

Se definen con fn, se llama con paréntesis y se usa return para devolver un valor. Los parámetros omitidos se inicializan con nil.

fn suma(a, b)
    return a + b

print(suma(2, 3))

print es la única función nativa registrada; imprime sus argumentos separados por espacios y termina con salto de línea.

Módulos y visibilidad

El lenguaje reconoce import ruta.modulo, mod nombre y el modificador pub para exportar funciones, variables y módulos. La resolución busca <ruta>/mod.luna y después <ruta>.luna, y detecta imports circulares.

Estas construcciones están en la gramática y en el cargador de módulos, pero el compilador actual aún no las emite.

Biblioteca estándar

Luna incluye las funciones globales len, type, str, int, float e input, además de los módulos math, string, table, list, io, os, time y path. Cada carpeta de Lib/ reparte su implementación en varios archivos .luna; la capa nativa en C queda oculta tras módulos _native.

import math
import string

print(math.sqrt(16))
print(string.upper("luna"))

Manejo de errores

Las sentencias try / catch nombre y throw expresion están disponibles desde código fuente. Los errores de runtime, como la división por cero, se convierten en excepciones capturables.

API C

Los encabezados públicos están en include/luna/: luna.h, luna.hpp y luna_types.h. La API ofrece gestión de runtime y estado (luna_runtime_new, luna_new), ejecución (luna_dofile, luna_dostring, luna_call, luna_pcall), pila, comprobación de tipos, tablas y listas, referencias, registro de funciones y módulos.

#include <luna/luna.h>

LunaState *L = luna_new(NULL);
luna_dostring(L, "print(1 + 2)", "=ejemplo");
luna_close(L);

Una función nativa devuelve el número de resultados apilados; un valor negativo señala error con el mensaje en el tope de la pila.

Estado y límites

Luna es 0.7.5 (ABI 1) y se distribuye bajo GPL-3.0. Parte de la gramática aún no está implementada de extremo a extremo: for, break, continue y lambdas anónimas.
