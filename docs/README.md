# Documentación de Luna

Esta carpeta organiza la documentación del lenguaje **Luna** `0.7.6` en tres áreas:

| Área | Contenido |
| --- | --- |
| [`Web/`](Web/) | Documentación web: `index.html`, `styles.css` y `script.js`. |
| [`MD/`](MD/) | Documentación Markdown del lenguaje: sintaxis, tipos, control de flujo, CLI, API C, FFI y proyectos. |
| [`Ayuda/`](Ayuda/) | Material de apoyo: actualizaciones, información general y archivos extra. |

## Ruta de aprendizaje

1. [Inicio rápido](MD/01-inicio-rapido.md): compila y ejecuta tu primer programa.
2. [Ruta guiada en el índice MD](MD/README.md): sintaxis, tipos, funciones y colecciones.
3. [Primer proyecto](MD/16-primer-proyecto.md): Mini agenda con listas, tablas y errores.
4. [FFI](MD/15-ffi.md) y [biblioteca estándar](MD/14-biblioteca-estandar.md): amplía el alcance.

## Estado de la documentación

Luna está en desarrollo. La documentación distingue entre lo que ya funciona de extremo a extremo y lo que solo está reconocido por el parser: consulta [estado de implementación](MD/11-estado-de-implementacion.md) antes de usar una característica.
