    Observatorio lunar · v0.7.6 · ABI 1

    Aprende Luna en 20 minutos y escribe tu primer programa.

    Luna es un lenguaje pequeño, embebible y con CLI estilo Python. Esta web es autocontenida: sigue la ruta, copia los ejemplos y ejecútalos sin consultar fuentes externas.

    Requiere un compilador C11 y Python 3. La sintaxis y la API C pueden cambiar entre versiones; no se recomienda uso en producción.

    Sintaxis

    La indentación define los bloques. Usa espacios (4 por nivel): los tabuladores en la indentación son un error.

    • Las cabeceras de bloque terminan en : y van seguidas de una línea indentada. Aplica a fn, if, else if, else, while, try y catch.
    • El carácter # inicia un comentario de línea fuera de las cadenas.
    • let declara variables reasignables; const declara variables que no pueden reasignarse.
    • mod nombre es una declaración de módulo, no una cabecera de bloque: no lleva :.
    let nombre = "Luna"
const pi = 3.14159

fn saludar(quien):
    print("Hola", quien)

saludar(nombre)
    Hola Luna

    Palabras reservadas

    and break catch const continue else extern false fn for if import in let mod nil not or pub return throw true try while

    Ojo: for, break y continue están en la lista de palabras reservadas, pero el compilador actual no emite código para ellos. Consulta control de flujo.

    Operadores

    De menor a mayor precedencia. La asociatividad indica cómo se agrupan operadores del mismo nivel.

    NivelOperadoresAsociatividad

    La división / y la potencia ** producen float; dividir entre cero es un error capturable. Las asignaciones compuestas +=, -=, *= y /= funcionan con variables, índices y campos.

    Funciones

    Se definen con fn nombre(parámetros):, se llaman con paréntesis y devuelven valores con return. Los parámetros omitidos se inicializan con nil.

    fn suma(a, b):
    return a + b

print(suma(2, 3))
    5

    Recursión

    fn deep(n):
    if n == 0:
        return 0
    return 1 + deep(n - 1)

print(deep(150))
    150

    Closures

    Una función definida dentro de otra captura las variables de su entorno. Aquí get y set comparten la misma variable x.

    fn make():
    let x = 10
    fn get():
        return x
    fn set(v):
        x = v
    return [get, set]

let p = make()
print(p[0]())
p[1](99)
print(p[0]())
    10
99

    print es una nativa, pero no la única: len, type, str, int, float e input y los módulos de la biblioteca estándar también registran sus propias nativas.

    Colecciones

    Listas y tablas literales con indexación, acceso a campos y asignación compuesta.

nums[1] += 5
print(nums[0], nums[1])

let config = { host = "localhost", port = 8080 }
print(config.host, config.port)
config.port += 100
config["port"] += 1
print(config.port)

list.push(nums, 40)
print(list.first(nums), list.last(nums))
print(table.has(config, "host"))
print(table.get(config, "port"))

    El módulo list expone new, push, pop, get, set, len, first, last, map, filter y reduce, entre otros. El módulo table expone new, get, set, has, keys, values y merge.

    Módulos y visibilidad

    Un archivo saludo.luna declara el módulo con mod saludo, y pub marca lo que se exporta. Otro archivo lo consume con import saludo.

    saludo.luna

    mod saludo

pub let VERSION = 1

pub fn hola():
    return "Hola desde saludo"

    main.luna

    import saludo

fn main():
    print("Probando imports")
    print(saludo.hola())
    print(saludo.VERSION)

main()
    Probando imports
Hola desde saludo
1

    import ruta.modulo resuelve primero <ruta>/mod.luna y después <ruta>.luna. El cargador detecta imports circulares. mod nombre no abre un bloque, por eso no lleva :; las funciones y variables declaradas dentro sí usan : en sus cabeceras.

    Estado: import, mod, pub y el acceso obj.campo están compilados y disponibles en 0.7.6.

    Errores y diagnósticos

    try: y catch e: capturan errores de ejecución, incluidos los errores convertidos en excepciones como la división por cero. throw expresion lanza un valor.

    try:
    throw "boom"
catch e:
    print("caught:", e)

try:
    print(1 / 0)
catch e:
    print("caught:", e)

print("after")
    caught: boom
caught: division by zero
after

    Un diagnóstico real

    Este programa intenta reasignar una constante:

    const x = 1
x = 2
      File "ejemplo.luna", line 2
    x = 2
    ^
SyntaxError: cannot reassign 'const' variable

    La CLI también ofrece una forma compacta: luna: cannot reassign 'const' variable. Los diagnósticos usan nombres de tipo estilo Python (SyntaxError, IndentationError, TypeError…), sin códigos numéricos, y pueden mostrar varios errores en un mismo pase con --max-errors=N.

    Proyecto guiado: Mini agenda

    Un solo archivo, agenda.luna, que puedes copiar tal cual. Usa una lista de tablas, funciones, while, if, try/catch y una entrada opcional protegida.

    import list

fn anadir(agenda, nombre, telefono):
    list.push(agenda, { nombre = nombre, telefono = telefono })
    print("Anadido:", nombre)

fn mostrar(agenda):
    if len(agenda) == 0:
        print("Agenda vacia")
        return nil
    let i = 0
    while i < len(agenda):
        let entry = agenda[i]
        print(i, entry.nombre, entry.telefono)
        i += 1

fn buscar(agenda, nombre):
    let i = 0
    while i < len(agenda):
        if agenda[i].nombre == nombre:
            print("Encontrado:", agenda[i].telefono)
            return nil
        i += 1
    print("No encontrado:", nombre)

let agenda = []
anadir(agenda, "Ada", "555-0100")
anadir(agenda, "Linus", "555-0200")
mostrar(agenda)
buscar(agenda, "Ada")

let interactivo = false
if interactivo:
    try:
        let nombre = input("Nombre: ")
        buscar(agenda, nombre)
    catch e:
        print("Entrada no disponible:", e)

print("Fin de la agenda")

    Salida esperada

    Anadido: Ada
Anadido: Linus
0 Ada 555-0100
1 Linus 555-0200
Encontrado: 555-0100
Fin de la agenda
    Observa: no hace falta concatenar cadenas. print admite varios argumentos y los separa con espacios. La entrada interactiva se activa cambiando interactivo a true; si falla, el catch mantiene el programa en marcha.
    Reto: añadir una función eliminar

    Recorre la lista con while, compara agenda[i].nombre y usa list.pop(agenda, i) cuando encuentres el nombre. Devuelve nil al terminar.

    HTTP

    El módulo http añade un cliente HTTP/1.1 y un servidor básico sobre http_native. No incluye TLS: las URL https:// se rechazan con un error explícito.

    import http

let response = http.get("http://127.0.0.1:8080/index.html", {timeout = 3})
print(response.ok)
print(response.status)
print(response.body)
    import http
import string

fn handler(req):
    return http.text(string.concat("recibido: ", req.body), nil)

let server = http.listen("127.0.0.1", 8080)
http.serve(server, handler, 4, 1)
http.close(server)

    JSON, CSV y GML

    json serializa tablas y listas anidadas, csv trabaja con filas delimitadas y gml crea ventanas con botones y campos de texto mediante un backend Tkinter.

    import json
import csv

let data = {nombre = "Luna", numeros = [1, 2, 3]}
print(json.pretty(data))
let rows = csv.parse("a,1\nb,2\n")
print(csv.encode(rows, ";"))
    import gml

let app = gml.app()
let win = gml.window(app, "Hola", 420, 200)
let field = gml.entry(app, win, "", 20, 20, 180, 28)

fn handler(event):
    if event.type == "click":
        print(gml.get_text(app, field))
        gml.quit(app)

gml.button(app, win, "Aceptar", 20, 70, 120, 32)
gml.run(app, handler, 16)

    gml requiere python3 con tkinter y un servidor de pantalla. La global input(mensaje) lee texto desde la terminal; el mensaje es opcional.

    FFI: llamar a C desde Luna

    La declaración extern nombre("librería", "firma") enlaza una función C. Equivale a let nombre = __ffi_declare("librería", "nombre", "firma").

    Firma y tipos

    La firma es "retorno(arg1,arg2,...)". Tipos aceptados: void, int o i64, float, f64 o double, str, string o cstr, y ptr o pointer.

    AliasLibreríaEjemplo
    "", "c", "libc"ABI de Cextern strlen("c", "int(str)")
    "self"El propio procesosímbolos ya cargados
    "m", "libm"Biblioteca matemáticaextern pow("m", "float(float,float)")
     
    extern strlen("c", "int(str)")
extern abs("c", "int(int)")
extern pow("m", "float(float,float)")

import ffi

let abs2 = ffi.declare("abs", "c", "int(int)")
let pow2 = ffi.declare_symbol("pow", "pow", "m", "float(float,float)")

print(strlen("luna"))
print(abs(-7))
print(abs2(-9))
print(pow(2.0, 3.0))
print(pow2(2.0, 4.0))
    4
7
9
8
16

    El módulo ffi permite además load y extension para trabajar con bibliotecas dinámicas.

    Límites: hasta 8 parámetros declarados y 4 argumentos por llamada; los argumentos deben ser homogéneos (no mezcles float con enteros, punteros o cadenas). Solo se admite ABI C: una biblioteca C++ debe exportar con extern "C". Una firma incompleta como extern foo("c") produce un SyntaxError.

    API C

    Los encabezados públicos están en include/luna/: luna.h, luna.hpp y luna_types.h. La API cubre creación de estado, ejecución, pila, comprobación de tipos, tablas y listas, referencias y registro de nativas.

    #include <luna/luna.h>

int main(void) {
    LunaState *L = luna_new(NULL);
    luna_dostring(L, "print(1 + 2)", "=ejemplo");
    luna_close(L);
    return 0;
}

    Una función nativa registrada devuelve el número de resultados apilados; un valor negativo señala error y deja el mensaje en el tope de la pila. Consulta 10 — API C.

    Estado y límites

    Luna 0.7.6 usa ABI 1 y se distribuye bajo GPL-3.0.

    ConstrucciónEstado real
    for ... inReconocido por el parser; el compilador informa de que no está implementado.
    break, continueReconocidos, sin generación de código.
    Lambdas anónimas fn(...)Nodo de AST reconocido, sin compilar.
    Concatenación de cadenas con +Error de tipo en tiempo de ejecución; usa print o string.join.
    FFI externDisponible en el árbol de trabajo de 0.7.6. Ver FFI.

    Otros límites: indentación solo con espacios, profundidad máxima de 256 niveles, cadenas solo con comillas dobles y floats impresos con %g. La sintaxis y la API C pueden cambiar; no se recomienda uso en producción.
