# Documentación de Luna

Esta carpeta organiza la documentación del lenguaje **Luna** en tres áreas:

| Área | Contenido |
| --- | --- |
| [`Web/`](Web/) | Documentación web: `index.html`, `styles.css` y `script.js`. |
| [`MD/`](MD/) | Documentación Markdown del lenguaje: sintaxis, tipos, control de flujo, CLI y API C. |
| [`Ayuda/`](Ayuda/) | Material de apoyo: actualizaciones, información general y archivos extra. |

## Índice rápido

- [Documentación web](Web/index.html) — abre `index.html` en el navegador.
- [Índice de la documentación Markdown](MD/README.md).
- [Índice del material de apoyo](Ayuda/README.md).

## Estado de la documentación

Luna está en desarrollo (versión `0.1.0`). La documentación distingue entre lo que ya funciona de extremo a extremo y lo que solo está reconocido por el parser. Consulta [estado de implementación](MD/11-estado-de-implementacion.md) antes de usar una característica.
